Section 01
Crucial macOS Keyboard Shortcuts

    

    
Mac shortcuts are built from modifier keys held down while you press a letter or number. If you're coming from Windows, the big one to rewire is ⌘ Command: it does what Ctrl does on a PC (copy, paste, save, quit). Tap any key combo below to see it "pressed".


    

      
The four modifier keys

      

        

          
⌘

          
Command cmd

          
Your main shortcut key — copy, paste, save, close, quit.

          ≈ Ctrl on Windows
        

        

          
⌥

          
Option opt / alt

          
Alternate actions and special characters (⌥ + G = ©). Hold it in menus to reveal hidden items.

          ≈ Alt on Windows
        

        

          
⌃

          
Control ctrl

          
⌃-click acts as a right-click. In Terminal it's the classic Unix Ctrl (⌃C to stop a command).

          ≈ Right-click / Unix Ctrl
        

        

          
⇧

          
Shift shift

          
Capitals, and it often "reverses" or extends a shortcut (⌘Z undo → ⌘⇧Z redo).

          Same as Windows
        

        

          
🌐

          
Globe fn

          
Bottom-left key. 🌐 + E opens emoji, 🌐 + F toggles full screen, and it turns the top row into F1–F12.

          ≈ Fn on Windows laptops
        

      

      

        Try it: hold ⌘, ⌥, ⌃ or ⇧ on your keyboard — the matching key lights up.

Section 02
Trackpad Gestures & Force Click Setup

    

    
The M1 Air's glass trackpad is multi-touch: it counts how many fingers you use and which way they move. Learning five or six gestures lets you right-click, survey every window, open apps and peek at notifications without touching the keyboard or hunting for menu items — often faster than any shortcut.


    

      
Where to set it up

      
    
        
  1. Open System Settings
    Click the Apple menu (top-left logo) › System Settings…, or press  and type "Trackpad".
    2. 
        
  2. Choose Trackpad in the sidebar
    System Settings›Trackpad — it's near the bottom of the list.
    3. 
        
  3. Use the three tabs at the top
    Point & Click (clicking, Force Click, tap to click), Scroll & Zoom (natural scrolling, pinch), and More Gestures (Mission Control, Notification Center, Launchpad). Each option plays a short demo video when you hover it.
    4. 
      

    


    

    

      
Gestures breakdown hover to animate

      

        

          
          
Point & Click

          
2-finger tap → Secondary (right) click

          
Opens context menus anywhere. Tapping needs Tap to click on — otherwise click with two fingers, or ⌃-click.

          
        

        

          
          
More Gestures

          
3-finger swipe up → Mission Control

          
See every open window and desktop at once; swipe down to return. The F3 key does the same.

          
        

        

          
          
More Gestures

          
Pinch thumb + 3 fingers → Launchpad

          
A full-screen grid of every app. On macOS Tahoe 26 the same pinch opens the new Apps view instead. Spread the same fingers to show the desktop.

          
        

        

          
          
More Gestures

          
2-finger swipe from right edge → Notification Center

          
Start off the right edge of the trackpad and swipe left. Clicking the clock in the menu bar opens it too.

          
        

        

          
          
More Gestures

          
2-finger swipe left/right → Back / Forward

          
Go back or forward a page in Safari, Finder and most apps — no need to find the arrow buttons.

          
        

        

          
          
More Gestures

          
3-finger swipe left/right → Switch desktops

          
Move between desktops (Spaces) and full-screen apps — great with one app per desktop.

          
        

      

    


    

      
Force Click & haptic feedback

      

        
    
          
  1. Turn on Force Click
    Trackpad›Point & Click›Force Click and haptic feedback
    The trackpad doesn't physically move — a haptic motor fakes the "click". With this on, a firmer second press triggers extra actions.
    2. 
          
  2. Adjust click pressure
    Drag the Click slider: Light, Medium or Firm. This sets how hard you press and how strong the haptic "thunk" feels. Start on Light if clicks feel heavy.
    3. 
          
  3. Choose how Look Up works
    Set Look up & data detectors to "Force Click with One Finger" (or "Tap with Three Fingers" if you prefer a lighter touch).
    4. 
        

        

          
          
What you can Force Click

          
    
            
  • A word → dictionary & look-up
    • 
            
  • A link in Safari or Mail → live preview
    • 
            
  • A file in Finder → Quick Look
    • 
            
  • A file or folder name → rename it
    • 
            
  • A date, address or flight number → add to Calendar / Maps
    • 
            
  • A Dock icon → that app's windows (App Exposé)
    • 
          

        

      

      

        

          Bonus: turn on three-finger dragMove windows and select text without holding a click
          

            
System Settings›Accessibility›Pointer Control›Trackpad Options…

            
Turn on Use trackpad for dragging and set Dragging style to Three-Finger Drag. Now just glide three fingers over a window's title bar to move it.

            
Three-finger drag takes over three-finger swipes, so macOS moves Mission Control and switching desktops to four fingers automatically.

          

        

        

          A gesture isn't working?Quick checks
          

            
1) Check it's switched on in More Gestures and note whether it's set to three or four fingers. 2) Notification Center must start off the right edge. 3) Corporate device-management profiles can disable some gestures — ask IT if a toggle is greyed out.

          

        

      

    

  


  
  

    

      

      
Section 03

Safari hides its developer tools by default. One checkbox adds a Develop menu to the menu bar and a Developer tab to Safari's settings. That gives you the Web Inspector (elements, console, network, storage), Responsive Design Mode, cache controls, user-agent switching, and remote inspection of web pages and WebViews on an iPhone or the iOS Simulator.


    

      
Exact steps

      
    
        
  1. Open Safari › Settings…
    With Safari in front, choose Safari › Settings… from the menu bar (called "Preferences" on older macOS) or press:
    2. 
        
  2. Go to the Advanced tab
    It's the last icon (a gear) in the settings toolbar — 1 in the illustration.
    3. 
        
  3. Check "Show features for web developers"
    At the bottom of the Advanced tab — 2. On Safari 16 and earlier the box is labelled "Show Develop menu in menu bar".
    4. 
        
  4. Confirm the Develop menu appears
    A new Develop menu sits between Bookmarks and Window. Right-click any page › Inspect Element, or press .
    5.

Develop

Section 04
Homebrew Setup — Dual Scenario Guide

    

    
Homebrew is the package manager for macOS, the Mac's apt. One command downloads, installs and updates developer tools (formulae such as git, wget, node) and desktop apps (casks such as VS Code or Chrome). It also handles dependencies, keeps everything in one place, and brew upgrade updates it all at once.


    

      brew.sh — official site
      Installation docs
      Homebrew Formulae
    


    

    

      
Which scenario are you?

      

        

          Scenario A
          
You have admin access

          
Your account can approve installs with your password: a personal Mac, or a work Mac where you're a local admin. Use the standard installer; it's fastest and fully supported.

          
        

        

          Scenario B
          
Restricted / corporate Mac

          
Installs ask for an administrator you don't have, or sudo is blocked by IT. Use the user-space install into ~/homebrew; no admin rights are needed.

          
        

      

      
Not sure? This prints which scenario fits your account:

      
am I an admin?

        
id -Gn | grep -qw admin && echo "Admin → use Scenario A" || echo "No admin → use Scenario B"

      
Open Terminal with , type Terminal and press . Paste with ⌘V, then press Return.

    


    

      

        
        
      

    


    
    

      
Scenario A · Admin access (standard installation)

      
Installs to /opt/homebrew, the official location on Apple Silicon Macs like the M1. You'll be asked for your Mac login password once.

      
    
        
  1. 
          
    Run the official installer
    
          
    Downloads and runs Homebrew's install script. It explains what it will do and waits for Return before starting. It also installs Apple's Command Line Tools if they're missing, which can take a few minutes.
    
          
    zsh — ~
    
            
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    
          
    When it asks for Password:, type your Mac login password. Nothing appears as you type, not even dots. That's normal; just press Return.
    
        
    2. 
        
  2. 
          
    Add brew to your PATH (Apple Silicon M1)
    
          
    On M1, Homebrew lives in /opt/homebrew, which isn't on the shell's PATH by default. brew shellenv sets PATH, MANPATH and related variables in every new Terminal window.
    
          
    zsh — ~
    
            
    echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zshrc
    
          
    The installer's "Next steps" message suggests ~/.zprofile instead. Either file works in Terminal; just don't add the line to both.
    
        
    3. 
        
  3. 
          
    Activate it now and verify
    
          
    Reload the profile in this window, then check that brew runs.
    
          
    zsh — ~
    
            
    source ~/.zshrcbrew --versionbrew doctor
    
          
    brew doctor should end with "Your system is ready to brew."
    
        
    4. 
      


      
    


    
    

      
Scenario B · Restricted / corporate user-space installation (no sudo)

      
Homebrew is unpacked directly into ~/homebrew, a folder in your own home directory. You already own everything there, so nothing ever asks for an administrator password, and removing it is as simple as deleting the folder.


      

        
Know the trade-off. Homebrew calls custom locations "unsupported". Prebuilt packages ("bottles") are built for /opt/homebrew, so in ~/homebrew many formulae compile from source. Small tools still install in seconds; big ones like node or python can take a while.

        
Compiling and brew update need Apple's Command Line Tools (they include git). They're already there if Xcode is installed; otherwise run xcode-select --install, or ask IT if it's blocked.

      


      
    
        
  1. 
          
    Create the Homebrew folder
    
          
    -p means no error if the folder already exists.
    
          
    zsh — ~
    
            
    mkdir -p ~/homebrew
    
        
    2. 
        
  2. 
          
    Download and extract Homebrew, without sudo
    
          
    curl streams the latest Homebrew from GitHub straight into tar, which unpacks it into ~/homebrew. --strip-components 1 drops the archive's top-level folder.
    
          
    zsh — ~
    
            
    curl -L https://github.com/Homebrew/brew/tarball/master | tar xz --strip-components 1 -C ~/homebrew
    
        
    3. 
        
  3. 
          
    Add ~/homebrew/bin to your PATH
    
          
    Appends one line to ~/.zshrc, so every new Terminal window can find brew. zsh has been the default shell since macOS Catalina; on bash, use ~/.bash_profile.
    
          
    zsh — ~
    
            
    echo 'export PATH="$HOME/homebrew/bin:$PATH"' >> ~/.zshrc
    
        
    4. 
        
  4. 
          
    Reload your shell and update Homebrew
    
          
    The first brew update sets up Homebrew's git repository and downloads the package index, so give it a minute or two. If it complains, run brew update --force.
    
          
    zsh — ~
    
            
    source ~/.zshrc && brew update
    
          
    verify (optional)
    
            
    which brew/Users/you/homebrew/bin/brew
    
          
    brew doctor will warn that your prefix isn't /opt/homebrew. That warning is expected with this method.
    
        
    5. 
      


      
    


    

      
A vs B at a glance

PATH lineeval "$(/opt/homebrew/bin/brew shellenv)"export PATH="$HOME/homebrew/bin:$PATH"

Pick one, not both. If you get admin rights later and switch to Scenario A, remove the ~/homebrew PATH line from ~/.zshrc first, so two copies of brew don't fight over your PATH.

Section 05

One catch: these are BSD versions, not GNU, so a few flags differ. For example sed -i '' needs an empty suffix, and ls --color is ls -G. If a Linux script breaks, brew install coreutils adds the GNU tools with a g prefix (gls, gsed…).

Section 06
Installing Apps from .dmg Files

    

    
A .dmg (disk image) is how most Mac apps are delivered outside the App Store. Think of it as a virtual USB stick: double-click it and a temporary drive appears in Finder with the app inside. The .dmg is only the box the app comes in, not the app itself. You copy the app out, then throw the box away.


    

      
Install in 5 steps

      
    
        
  1. Download the .dmg
    It lands in your Downloads folder, e.g. PrettyApp-2.4.dmg. Only download from the developer's official website.
    2. 
        
  2. Double-click to open (mount) it
    macOS checks the file for a moment, then opens a window with the app and usually an Applications folder shortcut next to it. A new drive also appears in Finder's sidebar under Locations.
    3. 
        
  3. Drag the app onto Applications
    Drag the app icon onto the Applications folder in that window. This copies the app onto your Mac, and that copy is the actual install.
    4. 
        
  4. Eject the disk image
    Click the ⏏ eject button next to it in the Finder sidebar, select it and press , or drag its icon to the Bin (the Bin turns into an eject icon).
    5. 
        
  5. Delete the .dmg
    In Downloads, select the .dmg and press  to move it to the Bin. You don't need it any more. If you ever need the app again, download a fresh copy.
    6. 
      


      

      
    


    

      
First launch & common gotchas

      

        

          First open
          
"Downloaded from the Internet" warning

          
The first time you open the app, macOS asks if you're sure. If you trust where it came from, click Open. It only asks once.

        

        

          Blocked?
          
"Apple could not verify…"

          
Click Done, then go to System Settings›Privacy & Security, scroll down and click Open Anyway. Only do this for apps you trust.

        

        

          Don't
          
Don't run the app from inside the .dmg

          
It may seem to work, but it disappears when the disk is ejected, and updates and settings often don't save. Always copy it into Applications first.

        

        

          Variant
          
Found a .pkg inside instead?

          
Some disk images contain an installer (.pkg) instead of an app. Double-click it and follow the steps, then eject and delete the .dmg as usual.

        

        

          Uninstall
          
Removing the app later

          
Open Applications in Finder and drag the app to the Bin (or press ). That's it.

        

        

          Shortcut
          
Skip the .dmg with Homebrew

          
Many apps can be installed with one command, with no window, dragging or ejecting (see Section 04).

          
brew install --cask firefox

        

      

    


    

      
Terminal versions

      

        
hdiutil attach: mount a .dmg
Same as double-clicking it.
hdiutil attach ~/Downloads/PrettyApp-2.4.dmg

        
hdiutil detach: eject it

hdiutil detach /Volumes/PrettyApp

        
Bin every .dmg in Downloads

Section 07
Recommended M1 Mac Initial Tweaks

    

    
The M1 is efficient out of the box, often 15+ hours on a charge, but a few settings make it better: a healthier battery, a display that doesn't change brightness on its own, and a Spotlight that finds what you need. Tick items off as you go; your progress is saved in this browser.


    

      
      
0 of 0 doneSetup checklist

      
    


    

      Battery optimisationLonger life per charge and per year
      

        
    
          
  • Keep Optimized Battery Charging on
    Battery›Battery Health ⓘ›Optimized Battery Charging
    Learns your routine and holds the charge at 80% until you need it, which slows battery wear when you're plugged in all day.
    • 
          
  • Low Power Mode on battery
    Battery›Low Power Mode›Only on Battery
    Slightly lowers peak performance and background activity. On M1 you'll barely notice the speed difference.
    • 
          
  • Slightly dim the display on battery
    Battery›Options…
    The screen is the biggest power draw, and a small dim adds real time.
    • 
          
  • Show battery percentage in the menu bar
    Control Center›Battery›Show Percentage
    On macOS Tahoe this lives under Menu Bar settings.
    • 
          
  • Find battery-hungry apps
    Activity Monitor›Energy
    Sort by "12 hr Power". Clicking the battery icon in the menu bar also lists apps using significant energy.
    • 
        

      

    


    

      Display & brightnessStop auto-brightness spikes
      

        
    
          
  • Turn off "Automatically adjust brightness"
    Displays›Automatically adjust brightness
    The ambient-light sensor changes brightness when lighting shifts — a cloud, a desk lamp, someone walking past. Turn it off and set brightness yourself with F1 / F2.
    • 
          
  • Decide on True Tone
    Displays›True Tone
    Warms colours to match the room. Nice for reading; turn it off for design or colour-accurate work.
    • 
          
  • Schedule Night Shift
    Displays›Night Shift…›Sunset to Sunrise
    Warmer screen in the evening.
    • 
          
  • Tame the keyboard backlight
    Keyboard›Adjust keyboard brightness in low light
    Also set "Turn keyboard backlight off after inactivity" to save a little power.
    • 
        

      

    


    

      Spotlight search — your launcher, calculator and file finder
      

        
    
          
  • Make  a habit
    Type the first few letters of an app and press Return. It also does maths (128*4), conversions (5 km in miles, 100 usd in eur) and definitions.  reveals a result in Finder.
    • 
          
  • Trim result categories
    Spotlight›Search results
    Untick noise you never want (Fonts, Movies, Siri Suggestions…) so the right result is on top.
    • 
          
  • Exclude big dev folders from indexing
    Spotlight›Search Privacy…›+
    Add build output, DerivedData or huge repos. Less indexing churn, cleaner results. (Older macOS: Siri & Spotlight › Spotlight Privacy….)
    • 
        

      

    


    

      Everyday comfortSmall changes you'll feel daily
      

        
    
          
  • Enable Tap to click
    Trackpad›Point & Click›Tap to click
    • 
          
  • Show all file extensions
    Finder›Settings…›Advanced›Show all filename extensions
    • 
          
  • Show Finder's path bar
    Finder›View›Show Path Bar 
    • 
          
  • Auto-hide the Dock for more screen
    Desktop & Dock›Automatically hide and show the Dock 
    • 
          
  • Install the latest macOS updates
    General›Software Update
    Corporate Macs may defer updates via IT — follow their schedule.

Section 08
Using the Clipboard on Mac

    

    
The clipboard is the invisible place your Mac keeps whatever you last copied. It's always on, so  and  work straight away. Two extras are worth turning on: clipboard history (macOS Tahoe 26 keeps a list of everything you copied, not just the last item) and Universal Clipboard (copy on your iPhone, paste on your Mac).


    

      
Clipboard basics

      

        

          Everyday
          
Copy & paste

          
Select text, an image or a file, copy it, then click where it should go and paste. The clipboard holds one item until you copy something else.

          
then

        

        

          Peek
          
See what's on the clipboard

          
In Finder, choose Edit›Show Clipboard. A small window shows exactly what you copied last.

        

        

          Finder
          
Copy a file's full path

          
Select a file in Finder and copy its path, e.g. /Users/you/Desktop/notes.txt. Handy for Terminal.

          
        

        

          Finder
          
Cut & move a file

          
Finder has no ⌘X for files. Copy the file, then paste with ⌥ Option held to move it instead of duplicating it.

          
then

        

        

          Screenshot
          
Screenshot to the clipboard

          
Add ⌃ Control to a screenshot shortcut and the image goes on the clipboard instead of your Desktop.

          
        

        

          Text
          
Paste as plain text

          
Drops the fonts and colours from text copied off a website, so it matches the document you paste into.

          
        

      

    


    

      
Turn on clipboard history macOS Tahoe 26

      
It's off by default because it stores everything you copy. Turn it on once and Spotlight remembers your recent copies.

      
    
        
  1. Open Spotlight settings
    System Settings›Spotlight, or press  and type "Spotlight settings".
    2. 
        
  2. Switch on Results from Clipboard
    Scroll to the bottom and turn on Results from Clipboard. Spotlight now saves each item you copy.
    3. 
        
  3. Choose how long to keep items
    The default is 8 hours. Newer Tahoe updates also offer 7 days and 30 days. Pick the shortest one that suits you.
    4. 
      


      
    


    

      
Use clipboard history

      

        

          Open
          
Open your clipboard history

          
Open Spotlight, then press ⌘4 to jump to the Clipboard view (⌘1 Apps, ⌘2 Files, ⌘3 Actions).

          
        

        

          Paste
          
Paste an older item

          
Use the arrow keys to pick an item, press Return to copy it, then ⌘V it wherever you need it.

          
        

        

          Search
          
Search what you copied

          
Just start typing in the Clipboard view, e.g. "brew" or "http", to filter your history.

        

      


      

      
Privacy tip: history keeps everything you copy, including passwords or card numbers you paste by hand. If you copy sensitive things often, stick with 8 hours, or turn the toggle off and on again to clear it.

    


    

      
On Sonoma or Sequoia? Use Maccy

      

        Free app
        
Maccy: clipboard history for older macOS

        
Before Tahoe, macOS only remembers your last copy. Maccy is a small, free, open-source app that adds history. Install it with Homebrew (Section 04), open it once, then press ⇧⌘C to see your list.

        
brew install --cask maccy

        

      

    


    

      
Universal Clipboard: iPhone ⇄ Mac

      
Copy on your iPhone or iPad, paste on your Mac, or the other way round. Nothing to install. It uses Handoff.

      
    
        
  1. Sign in with the same Apple Account
    Your Mac and iPhone must use the same Apple Account, with Wi-Fi and Bluetooth on and the devices near each other.
    2. 
        
  2. Turn on Handoff on the Mac
    System Settings›General›AirDrop & Handoff › turn on Allow Handoff between this Mac and your iCloud devices.
    3. 
        
  3. Turn on Handoff on the iPhone
    Settings›General›AirPlay & Continuity › turn on Handoff. (Older iOS calls it AirPlay & Handoff.)
    4. 
        
  4. Copy on one, paste on the other
    Copy as normal on the iPhone, then press  on the Mac. Paste soon after copying, because the shared item only lasts a short while.
    5. 
      


      

      

        Universal Clipboard not working?Quick checks
        

          
    
            
  • Both devices are signed in to the same Apple Account.
    • 
            
  • Wi-Fi and Bluetooth are on for both. They don't need the same network, but they must be close together.
    • 
            
  • Handoff is on for both devices. Turn it off and on again to reset it.
    • 
            
  • Still stuck? Restart both devices. That fixes it most of the time.
    • 
          

        

      

    


    

      
Clipboard in Terminal

Sends anything piped into it to the clipboard.

          
pwd | pbcopy

        

        

          
pbpaste: paste into a file

          
Prints the clipboard, so you can save it to a file.

          
pbpaste > notes.txt

        

      

    

  


  
  

    

    

      

      
Section 09 · Danger zone
Keep "System Data" from Eating Your Storage

    

    
Open System Settings›General›Storage and you'll likely see a big grey bar called System Data. It's where macOS puts everything that isn't an app or a document: caches, logs, crash reports, Time Machine snapshots, iPhone backups and developer leftovers. On a 256 GB M1 Air it can quietly grow past 50–100 GB.


    

      
      

        
Read this before deleting anything. Most of System Data is safe to clear, but some of it is macOS itself. Only delete what this section points to, quit the app first, and never delete folders inside /System.

        
If something looks unfamiliar, leave it. A full disk is annoying, but a broken system is much worse.

      

    


    

      
Never do these

      
    
        
  • No sudo rm -rf on system foldersDeleting from /System, /Library or /private/var by hand can stop your Mac from starting up.
    • 
        
  • No "Mac cleaner" appsApps that promise to free gigabytes in one click often delete too much, nag you to pay, or run in the background forever. Everything below is free and built in.
    • 
        
  • Don't delete the Caches folder itselfEmpty the folders inside ~/Library/Caches, not the folder. Apps expect it to exist.
    • 
      

    


    

      
See what's taking space

      
    
        
  1. Open Storage
    System Settings›General›Storage. Wait a minute or so. The bar fills in slowly while macOS adds things up.
    2. 
        
  2. Turn on the easy wins
    Under Recommendations, turn on Empty Trash Automatically (deletes items after 30 days in the Bin) and click Review Files to find big old downloads.
    3. 
        
  3. Find the biggest folders
    This lists the 15 biggest folders in your user Library, largest last:
    
          
    du -sh ~/Library/* 2>/dev/null | sort -h | tail -15
    4. 
      


      
    


    

      
Turn off system analytics

      
macOS shares crash and usage reports with Apple by default and keeps copies on your disk. Turning this off stops the uploads and some of the background logging.

      
    
        
  1. Open Analytics & Improvements
    System Settings›Privacy & Security›Analytics & Improvements (scroll down the Privacy & Security page).
    2. 
        
  2. Switch everything off
    Turn off Share Mac Analytics, Improve Siri & Dictation, Improve Assistive Voice Features, Share with app developers and Share iCloud Analytics.
    3. 
        
  3. Bonus: Personalised Ads
    Back on Privacy & Security, open Apple Advertising and turn off Personalized Ads.
    4. 
        
  4. Clear the old reports
    Click Analytics Data on the same page to see what's been saved. Old crash reports live in ~/Library/Logs/DiagnosticReports, and you can empty that folder.
    
          
    open ~/Library/Logs/DiagnosticReports
    5. 
      


      
    


    

      
Clear caches regularly once a month

      

        

          Caches
          
Your user caches

          
Quit your apps, then in Finder press  and open ~/Library/Caches. Delete the contents of the biggest app folders. Apps rebuild what they need.

          
du -sh ~/Library/Caches/* | sort -h | tail -10

        

        

          Safari
          
Browser caches

          
With the Develop menu on (Section 03): Develop › Empty Caches. You stay signed in and your history is kept. In Chrome, use Delete browsing data › Cached images.

          
        

        

          Homebrew
          
Homebrew leftovers

          
Removes old package versions and cached downloads.

          
brew cleanup --prune=all

        

        

          Developer
          
npm & pip caches

          
Package managers keep every download they've ever made. Clearing them is safe because they download again when needed.

          
npm cache clean --force

          
pip3 cache purge

        

        

          Developer
          
Xcode leftovers

          
Only if you use Xcode. DerivedData and old simulators can take up tens of GB.

          
rm -rf ~/Library/Developer/Xcode/DerivedData

          
xcrun simctl delete unavailable

        

        

          Developer
          
Docker images

          
Only if you use Docker. Removes stopped containers and unused images.

          
docker system prune

        

      

    


    

      
Other hidden space hogs

      

        Time Machine local snapshotsOften the single biggest part of System Data
        

          
If you use Time Machine, macOS keeps hourly snapshots on your internal disk. It deletes them when space runs low, but they still inflate System Data. List them, or ask macOS to trim them now:

          
tmutil listlocalsnapshots /

          
tmutil thinlocalsnapshots / 999999999999 4

        

      

      

        Old iPhone / iPad backupsCan be 10–50 GB each
        
In Storage, click the ⓘ next to iOS Files, select old backups and click Delete. If your iPhone already backs up to iCloud, you don't need a local copy.

      

      

        Messages & Mail attachmentsPhotos and videos pile up for years
        
In Messages › Settings › General, set Keep messages to 1 Year. In Storage › Messages you can review and delete large attachments.

      

      

        Downloads full of installers.dmg and .pkg files you already installed
        
After installing an app, drag its .dmg to the Bin. In Finder, switch Downloads to list view () and click the Size column to see the biggest files first.

      

      
Restart once a week. macOS clears temporary files and swap on every restart, so System Data often drops by a few GB on its own.
